# Security Policy

## Reporting a vulnerability

Do not report suspected vulnerabilities in public issues or pull requests.

Before making a public disclosure, privately contact
[@optimizoor on X](https://x.com/optimizoor). Alternatively, contact
[SEAL 911](https://github.com/security-alliance/seal-911), which can reach the Solady
maintainers.

This allows time to assess the impact and privately coordinate mitigations with downstream users.

If an automated agent finds a suspected vulnerability, have it prepare a report for human review.
Do not allow the agent to contact maintainers or publish the report automatically.
